# PureTune / 纯音工坊

Turn a reference instrumental track into original pure music, a JianYing video draft, and publish-ready copy.

从一首参考曲，自动生成原创纯音乐、剪映草稿和发布文案。

## What it does / 这个工具能做什么

- Analyze the exact reference file the user provides and extract musical information as completely as possible.
- 完整分析用户提供的参考曲，并尽可能完整地提取音乐信息。
- Write three Suno prompt versions: Safe, Recommended, Experimental.
- 根据分析结果写三版 Suno 提示词：保守版、推荐版、实验版。
- Generate songs on Suno through an automated Edge/CDP browser.
- 用自动化 Edge 在 Suno 批量生成歌曲。
- Record songs through system loopback when direct download is unavailable.
- 免费版无法下载时，通过系统回环录音获取歌曲。
- Analyze generated songs and assign Chinese + English names.
- 分析新曲并生成中英文名字。
- Rename files locally and on Suno with a numeric prefix.
- 本地文件和 Suno 标题同步改名并加序号。
- Organize everything under the reference-track folder.
- 按参考曲整理文件夹。
- Generate a JianYing draft.
- 生成剪映草稿。
- Generate titles, copy, and tags for Bilibili, Douyin, and Xiaohongshu.
- 生成三平台标题、正文和标签。

## Installation / 安装

```bash
python scripts/install.py
```

This script installs Python dependencies and checks for `ffmpeg` / `ffprobe`.
这个脚本会安装 Python 依赖，并检查 `ffmpeg` / `ffprobe`。

Optional environment variables / 可选环境变量：

- `PURETUNE_FFMPEG`
- `PURETUNE_FFPROBE`
- `PURETUNE_CDP_URL`
- `PURETUNE_OUTPUT_ROOT`
- `PURETUNE_JIANYING_DRAFT_LIB`
- `PURETUNE_SUNO_TOKEN`

## Usage flow / 使用流程

1. Tell the AI which reference track to use.
   告诉 AI 你的参考曲文件。
2. Choose the background image source: user-provided or auto-generated 1920x1080.
   选择背景图来源：用户提供，或自动生成 1920×1080。
3. Choose how copy should be written: generated by AI, or imitated from your template.
   选择文案生成方式：AI 生成，或按你的模板仿写。
4. The AI completes analysis, prompts, Suno generation, recording, naming, renaming, organization, JianYing draft, and copy.
   AI 会完成分析、提示词、Suno 生成、录音、起名、改名、整理、剪映草稿和文案。
5. You export from JianYing and publish.
   你只需要在剪映里导出，再上传到平台。

## Notes / 注意

- Reference-track analysis can take a long time. Please wait patiently.
- 分析参考曲可能比较耗时，请耐心等待。
- Suno's Variety slider inside More Options must be set to off before generation.
- Suno 生成前会把 More Options 里的 Variety 滑条设为 off。
- The JianYing step is currently tested mainly on Windows.
- 剪映步骤目前主要在 Windows 环境测试。
- JianYing 10.8 can generate drafts. Automatic export requires JianYing 6 or earlier; this skill only generates the draft and asks the user to export manually.
- 剪映 10.8 可以生成草稿；自动导出需要剪映 6 及以下版本。本技能只负责生成草稿，导出由用户手动完成。
