# Audio Analysis

Analyze the exact audio file the user provides. Do not replace it with another version; extract the available musical information as completely as possible from that file:

- BPM and time signature
- Key and mode
- Mood and energy
- Instrumentation and technique
- Dynamic range and production character
- Song structure and emotional arc

The analysis result should be saved under the reference track's `分析/` folder.

For the generated songs, run a lighter analysis pass to support naming:

- BPM, key, duration
- Energy, brightness, dynamics
- Whether strings or other instruments are present
- Theme grouping clues
