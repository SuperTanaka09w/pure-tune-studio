# Suno Prompt Writing

After analyzing the reference track, write three prompt versions:

- 保守版 (Safe): closest to the original reference style, fewer speculative tags.
- 推荐版 (Recommended): balanced, includes original-melody guidance to avoid copying.
- 实验版 (Experimental): more modern, condensed, or exploratory tags.

Each version must be stored in two forms:

1. Original continuous English prompt, ready to paste into Suno's Style field.
2. Markdown structured version, split into categories such as:

```markdown
## 乐器
- solo piano

## 风格
- romantic classical etude

## 调性
- C minor

## 速度
- 136 BPM

## 技法
- virtuosic technique
- fast shimmering runs

## 情绪与意境
- flickering mysterious will-o'-the-wisp mood
```

Do not delete the original continuous prompt when creating the Markdown version.
